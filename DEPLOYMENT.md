**Guía de Despliegue (Replicabilidad)**

Este documento explica el proceso general de despliegue del prototipo de reservas o turnos medicos cloud lite.

## Objetivo

- Explicar de manera técnica y sencilla el paso a paso del proceso de despliegue del prototipo para que la institución interesada en utilizarla pueda replicarla de manera correcta en su entorno.


## Requisitos

- Cuenta de Gmail.
- Google Drive.
- Google Sheets.
- App Script.
- Computadora.
- Cuenta de GitHub.
- Conocimientos en HTML, CSS, JavaScript y uso de los servicios de google (Drive, Google Sheets y App Script).

## Documentación

La siguiente carpeta contiene los siguientes archivos necesarios para el despliegue: 

- index.html 
- estilos.html (contiene todo el código css)
- codigo.gs
- plantilla.xlsx (se utiliza como base de datos)

También esta el archivo **Manual de despliegue.pdf** en donde se detalla el paso a paso y con imagenes la forma correcta de desplegar el prototipo.
